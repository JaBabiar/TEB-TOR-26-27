# Kartkówka: Formularz POST i dodawanie rekordów do bazy danych

**Cel zadania:**
Sprawdzenie umiejętności tworzenia formularzy HTML z wykorzystaniem metody POST, odbierania przesłanych danych w PHP oraz zapisywania nowych rekordów w bazie danych (zgodnie z wymaganiami egzaminu INF.03).

---

## Etap 1: Przygotowanie bazy danych (Sklep komputerowy)

Wykorzystaj bazę danych `sklep_komputerowy` oraz tabelę `produkty` (jeśli nie masz jej jeszcze utworzonej, wykonaj poniższy skrypt SQL):

```sql
CREATE DATABASE IF NOT EXISTS sklep_komputerowy CHARACTER SET utf8mb4 COLLATE utf8mb4_polish_ci;
USE sklep_komputerowy;

CREATE TABLE IF NOT EXISTS produkty (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nazwa VARCHAR(150) NOT NULL,
    kategoria VARCHAR(80) NOT NULL,
    producent VARCHAR(80) NOT NULL,
    cena DECIMAL(10, 2) NOT NULL
);

```

---

## Etap 2: Dodawanie nowego podzespołu (Metoda POST)

1. W pliku `dodaj.html` (lub `dodaj.php`) stwórz poprawny semantycznie formularz HTML wykorzystujący **metodę POST** (pamiętaj o atrybucie `lang="pl"` oraz powiązaniu każdego pola formularza ze znacznikiem `<label>`).
2. Formularz ma zawierać odpowiednie pola umożliwiające wpisanie danych nowego produktu:
* **Nazwa produktu** (`type="text"`),
* **Kategoria** (`type="text"` lub lista rozwijana `<select>` z kilkoma kategoriami do wyboru, np. *Procesory*, *Karty graficzne*, *Pamięć RAM*, *Dyski SSD*),
* **Producent** (`type="text"`),
* **Cena** (`type="number"` z atrybutem `step="0.01"`).


3. Formularz ma przesyłać dane do pliku `dodaj_produkt.php`.
4. W pliku `dodaj_produkt.php` napisz skrypt PHP, który:
* Nawiąże połączenie z bazą danych `sklep_komputerowy`.
* Sprawdzi, czy dane z formularza zostały przesłane (`isset` lub `!empty`), a następnie pobierze je z tablicy `$_POST`.
* Wykona zapytanie `INSERT INTO` dodające nowy rekord do tabeli `produkty`.
* Wyświetli krótki komunikat potwierdzający dodanie produktu (np. *„Produkt [nazwa] został pomyślnie dodany do bazy!”*) oraz zamknie połączenie z bazą danych (`mysqli_close`).
