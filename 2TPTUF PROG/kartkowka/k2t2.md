USE sklep_komputerowy;

CREATE TABLE IF NOT EXISTS produkty (
    id INT AUTO_INCREMENT PRIMARY KEY,
    nazwa VARCHAR(150) NOT NULL,
    kategoria VARCHAR(80) NOT NULL,
    producent VARCHAR(80) NOT NULL,

## Etap 2: Wyszukiwarka podzespołów (Metoda GET)

1. W pliku `index.html` (lub `index.php`) stwórz poprawny semantycznie formularz HTML wykorzystujący **metodę GET** (pamiętaj o atrybucie `lang="pl"` oraz powiązaniu pola `<input>` ze znacznikiem `<label>`).
2. Formularz ma przesyłać wpisane dane do nowego pliku o nazwie `szukaj_produktu.php`.
3. W pliku `szukaj_produktu.php` napisz skrypt PHP, który:
* Nawiąże połączenie z bazą danych `sklep_komputerowy`.
* Wykona zapytanie `SELECT` wyszukujące produkty zawierające wpisaną frazę w nazwie **lub** kategorii (np. używając operatora `LIKE '%...%'`).
* Zamknie połączenie z bazą danych po pobraniu wyników.
4. Wyświetl pobrane dane w czytelnej formie (np. lista `<ul>`, tabela `<table>` lub karty z nagłówkami/obramowaniem) tak, aby **każdy produkt był wyraźnie wizualnie oddzielony od pozostałych** i zawierał wszystkie informacje: nazwę, kategorię, producenta oraz cenę (wraz z dopiskiem `zł`).
