
Utwórz bazę `gry_baza` i tabelę `gry` wykonując poniższy kod SQL:

```sql
CREATE DATABASE IF NOT EXISTS gry_baza CHARACTER SET utf8mb4 COLLATE utf8mb4_polish_ci;
USE gry_baza;

CREATE TABLE IF NOT EXISTS gry (
    id INT AUTO_INCREMENT PRIMARY KEY,
    tytul VARCHAR(100) NOT NULL,
    gatunek VARCHAR(50) NOT NULL,
    ocena INT NOT NULL
);

```

### Krok 2: Formularz (`index.html`)

1. Utwórz poprawny dokument HTML (`lang="pl"`) z formularzem wysyłającym dane metodą **POST** do pliku `dodaj_gre.php`.
2. Umieść w nim 3 pola powiązane ze znacznikami `<label>`:
* **Tytuł gry** (`type="text"`),
* **Gatunek** (`type="text"`),
* **Ocena 1–10** (`type="number"`),
* Przycisk wysyłający (`type="submit"`).



### Krok 3: Skrypt PHP (`dodaj_gre.php`)

1. Połącz się z bazą `gry_baza` (`mysqli_connect`).
2. Sprawdź za pomocą `isset()`, czy dane z formularza zostały przesłane, i przypisz je z tablicy `$_POST` do zmiennych.
3. Wykonaj zapytanie `INSERT INTO gry (tytul, gatunek, ocena) VALUES (...)` za pomocą `mysqli_query()`.
4. Wyświetl komunikat: *„Dodano grę do bazy!”* i zamknij połączenie (`mysqli_close`).
