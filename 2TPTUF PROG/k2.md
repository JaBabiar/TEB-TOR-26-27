# Grupa 2: Obsługa plików w PHP
## Kartkówka - Obsługa plików w PHP
### Część 1 - Struktura katalogu
```sql
CREATE DATABASE IF NOT EXISTS kartkowka_pliki;
USE kartkowka_pliki;


CREATE TABLE pliki ( 
    id INT AUTO_INCREMENT PRIMARY KEY,
    nazwa_pliku varchar(100),
    rola varchar(50),
    opis varchar(200)
);

INSERT INTO pliki(nazwa_pliku, rola, opis) VALUES
('index.php', 'główny', 'strona początkowa strony'),
('style.css', 'styl', 'plik stylów CSS'),
('skrypt.php', 'funkcjonalny', 'pobiera dane z bazy i je przetwarza');
```

### Część 2 - Skrypt PHP

- Utworzenie połączenia z bazą danych i przypisanie go do zmiennej
-  Zapisanie do zmiennej zapytania pobierającego wszystkie dane z tabeli
-  Wysłanie zapytania do bazy danych i przypisanie wyniku do zmiennej
-  Pętla pobiera kolejne wiersze wyników i wypisuje na ekranie nazwę pliku i jego rolę
-  (na 6) - możliwość wyszukania pliku za pomocą linku lub formularza
