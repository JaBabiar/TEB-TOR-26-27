# 📘 Kompendium: Klasy w Pythonie (Podstawy)

## 1. Tworzenie klasy i inicjalizacja (`__init__`)
Klasa to "przepis" na tworzenie obiektów. Metoda `__init__` to konstruktor – wywołuje się automatycznie w momencie tworzenia nowego obiektu i służy do nadania mu początkowych cech (atrybutów).

```python
class Szkola:
    # Konstruktor - inicjalizuje atrybuty obiektu
    def __init__(self, nazwa, miasto):
        self.nazwa = nazwa      # atrybut instancji (nazwa szkoły)
        self.miasto = miasto    # atrybut instancji (miasto)
        self.klasy = []         # pusta lista, do której będziemy dodawać obiekty Klas
    
    # ... (metody opisane poniżej)
```
**💡 Ważne:** Słowo `self` oznacza "ten konkretny obiekt". Dzięki niemu każda szkoła pamięta swoje własne dane.

## 2. Zarządzanie danymi (Modyfikacja list w klasie)
Atrybut `self.klasy` to lista. Możemy ją modyfikować na dwa sposoby: bezpośrednio (poza klasą) lub używając metod (wewnątrz klasy - **zalecane**).

### Sposób A: Modyfikacja z zewnątrz (bezpośredni dostęp)
```python
moja_szkola = Szkola("ZST", "Warszawa")

# 1. append() - dodaje JEDEN element na koniec listy (Najczęstsze i najszybsze)
moja_szkola.klasy.append("Klasa 1A") 

# 2. += (lub extend) - łączy listy. Używamy, gdy dodajemy WIELE elementów naraz
moja_szkola.klasy += ["Klasa 2B", "Klasa 3C"] 
# lub
moja_szkola.klasy.extend(["Klasa 2B", "Klasa 3C"])
```

### Sposób B: Modyfikacja przez metodę klasy (Dobre praktyki / Enkapsulacja)
Zamiast "grzebać" w liście z zewnątrz, lepiej stworzyć metodę, która to zrobi.
```python
class Szkola:
    # ... (tutaj __init__ z punktu 1) ...

    def dodaj_klase(self, nowa_klasa):
        """Metoda dodająca nową klasę do szkoły"""
        self.klasy.append(nowa_klasa)
        print(f"Dodano {nowa_klasa} do szkoły {self.nazwa}.")

# Użycie:
moja_szkola.dodaj_klase("Klasa 4D")
```

## 3. Metoda `__str__` (Reprezentacja tekstowa)
Metody "magiczne" (zaczynające się i kończące podwójnym podkreśleniem `__`) mają specjalne znaczenie dla Pythona. 
Metoda `__str__` decyduje o tym, **co zobaczysz, gdy użyjesz funkcji `print()` na obiekcie**. Bez niej Python wyświetli tylko bezużyteczny adres pamięci (np. `<Szkola object at 0x7f8...>`).

```python
class Szkola:
    # ... (__init__ i dodaj_klase) ...

    def __str__(self):
        # Używamy f-stringów do czytelnego formatowania tekstu
        liczba_klas = len(self.klasy)
        return f"Szkoła: {self.nazwa} | Miasto: {self.miasto} | Liczba klas: {liczba_klas}"
```

## 🏆 Pełny, działający przykład (Podsumowanie)

Oto jak to wszystko wygląda połączone w jeden spójny kod:

```python
class Szkola:
    def __init__(self, nazwa, miasto):
        self.nazwa = nazwa
        self.miasto = miasto
        self.klasy = []

    def dodaj_klase(self, nazwa_klasy):
        self.klasy.append(nazwa_klasy)

    def __str__(self):
        return f"[{self.miasto}] {self.nazwa} - ma obecnie {len(self.klasy)} klas."

# --- TESTY ---

# 1. Tworzenie obiektu
szkola1 = Szkola("Liceum im. Mickiewicza", "Kraków")
szkola2 = Szkola("Podstawówka nr 5", "Gdańsk")

# 2. Dodawanie danych (użycie metody)
szkola1.dodaj_klase("1A")
szkola1.dodajaj_klase("2B")
szkola2.dodaj_klase("1A")

# 3. Wyświetlanie (automatyczne wywołanie __str__)
print(szkola1)  
# Wynik: [Kraków] Liceum im. Mickiewicza - ma obecnie 2 klas.

print(szkola2)  
# Wynik: [Gdańsk] Podstawówka nr 5 - ma obecnie 1 klas.
```

### 📝 Słowniczek pojęć z notatki:
* **`__init__`** - Konstruktor. Konfiguruje obiekt zaraz po jego stworzeniu.
* **`self`** - Uchwyt do aktualnego obiektu. Pozwala odróżnić atrybuty jednej szkoły od drugiej.
* **`.append()`** - Metoda listy dodająca jeden element na jej koniec.
* **`__str__`** - Metoda zwracająca "ludzki" (czytelny) ciąg znaków opisujący obiekt. Wywoływana przez `print()`.
