# Zadanie Praktyczne: Strona Osobista z PHP i CSS

## Cel Nauki
Nauka podstawowego łączenia PHP z HTML oraz stosowania prostego CSS do stylizacji strony.

---

## Wymagania Techniczne
- Plik główny: `index.php`
- Styl CSS w osobnym pliku: `style.css`
- Kod PHP wewnątrz znacznika `<body>` (nie na samej górze pliku!)

### 1️⃣ Strona Osobista

W pliku `index.php` wyświetl informację o sobie:
- Nazwisko i imię
- Klasa
- Data urodzenia
- Hobby


Dane pobierz z tablicy `$student` w PHP.

### 2️⃣ Stylizacja CSS

Stwórz plik `style.css` z:
- Kolorem tła (np. `background-color`)
- Kolorem tekstu (np. `color`)
- Rozmiarem czcionki (np. `font-size`)
- Zaokrąglonymi rogami kontenera (np. `border-radius`)

### 3️⃣ Układ

Użyj HTML5 z tagami semantycznymi:
`<header>`, `<main>`, `<footer>`

---

## Ocena
✅ Plik `index.php` z PHP wewnątrz `<body>`  
✅ Plik `style.css` z własnymi stylami  
✅ Użycie tagów semantycznych (`header`, `main`, `footer`)  
✅ Dane wyświetlane poprawnie i bezpiecznie (`htmlspecialchars`)
