# PZO (Przedmiotowy System Oceniania)  
  
## Liczba prac w semestrze  
- 3 kartkówki  
- 1 sprawdzian  
- 2 egzaminy na semestr  
- 1 projekt  
  
## System oceniania (progi procentowe)  
- 0% – 49% → **1** (niedostateczny)  
- 50% – 59% → **2** (dopuszczający)  
- 60% – 74% → **3** (dostateczny)  
- 75% – 84% → **4** (dobry)  
- 85% – 94% → **5** (bardzo dobry)  
- 95% – 100% → **6** (celujący)  
  
## Plusy i minusy za aktywność  
- 3 plusy (+) → ocena **5**  
- 6 plusów (+) → ocena **6**  
- 3 minusy (–) → ocena **1**
